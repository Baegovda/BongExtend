# BongExtend

치지직, 디시인사이드, 페이지 번역 기능을 하나로 합친 크롬 확장 프로그램이에요.
예전에 따로 쓰던 치지직 확장, 번역 확장, 디시 확장을 합쳤어요.

## 설치
1. [Releases](https://github.com/Baegovda/BongExtend/releases)에서 `bongextend-버전-chrome.zip`을 받아요 (Source code zip 아님).
2. 압축을 풀어요. 이 폴더가 설치 폴더예요. 지우거나 옮기지 마세요.
3. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 푼 폴더를 골라요. 크롬 109 이상이 필요해요.
4. 예전에 따로 쓰던 치지직·번역·디시 확장은 설정을 옮긴 뒤 지워요 (같이 켜 두면 기능이 두 번 돌아요).

## 팝업
툴바의 BongExtend 아이콘을 누르면 탭 네 개가 나와요. 탭을 끌어서 순서를 바꿀 수 있고, 탭에 초점을 둔 뒤 Alt+←/→로도 옮겨요. 로고를 더블클릭하면 처음 순서로 돌아가요.
- **치지직**: 버퍼링 자동 복구(다음 복구까지 남은 시간을 크게 보여줄 수 있어요), 화질 고정(기본 1080p, 720p·480p·360p도 고를 수 있어요), 선명한 화면, 넓은 화면, 들어가거나 새로고침하면 자동 재생, 영상 위 시청자 수, 채팅 제목 옆 시청자 수, 주간 랭킹 가리기, 후원 랭킹 닉네임 흐리게, 채팅 글씨 크기, 방향키 이동, 팔로잉 목록 새로고침, 관심 스트리머 자동 이동, 광고 자동 건너뛰기, 치트키 안내창 숨기기
- **번역**: 이 페이지만 켜고 끄는 스위치와, 이 사이트를 항상 번역하는 스위치가 따로 있어요. 항상 번역을 켜면 그 사이트 권한을 한 번 물어봐요. Gemini API 키는 **설정 열기**에서 넣어요. 마우스를 올리면 나오는 툴팁도 번역해요. 페이지에서 오른쪽 클릭 → "BongExtend: 페이지 번역 켜기/끄기"도 있어요.
- **디시**: 글 목록 새로고침, 미리보기, 콘텐츠 차단, 메모, 유저 정보, 레이아웃, 글꼴, 이미지 검색, 관리, 글쓰기, 스텔스. 안쪽 탭은 일반, 고급, 차단, 메모, 모듈, 데이터예요. 데이터 탭은 디시 설정만 클라우드에 백업하거나 초기화해요. 차단 목록과 메모 목록은 그 탭에서 따로 복사할 수 있어요.
- **업데이트·설정**: 업데이트 확인, 지금 업데이트, 설정 파일로 저장하고 불러오기. 저장 파일에는 Gemini API 키와 항상 번역할 사이트 목록이 들어 있으니 공유하지 마세요.

치지직·번역·디시 탭 위에 **모듈 사용** 스위치가 있어요. 업데이트·설정 탭에는 없어요. 끄면 그 기능이 통째로 꺼지고, 이미 열린 페이지는 새로고침(F5)하면 적용돼요.

## 업데이트
업데이트·설정 탭의 **하루에 한 번 자동 확인**은 기본으로 켜져 있어요. 직접 보려면 **업데이트 확인**을 눌러요. 새 버전이 있으면 **지금 업데이트**가 나와요. 누르면 새 탭이 열려요.

처음 한 번만, 크롬에 불러온 BongExtend 폴더(manifest.json이 있는 곳)를 골라요. 다음부터는 바뀐 파일만 넣고 확장을 다시 켜요. 중간에 멈추면 그 탭의 **멈춘 업데이트 마저 설치**로 이어서 해요. 이미 열려 있던 페이지는 새로고침(F5)해 주세요.

zip만 받아 직접 덮어쓰려면 **zip 내려받기**를 써요. 그러면 받은 파일을 설치 폴더에 풀어 덮어쓴 뒤, 확장 프로그램 화면에서 새로고침해 주세요.

## 옛 확장에서 설정 옮기기
확장 ID가 새로 바뀌어서 설정이 자동으로 넘어오지 않아요.
- **번역**: 예전 번역 확장이 만든 `bongtrans-settings.json`을 BongExtend 업데이트·설정 탭 → **파일 불러오기**에 넣어요. Gemini 키도 같이 넘어와요.
- **디시**: 예전 디시 확장 팝업 → 데이터 → **데이터 내보내기**(클립보드에 복사돼요) → BongExtend 업데이트·설정 탭 → **붙여넣어 불러오기**에 붙여 넣어요.
- **치지직**: 예전 치지직 확장에는 내보내기 버튼이 없어서 치지직 탭에서 다시 설정해 주세요. 관심 스트리머 목록도 그래요.

BongExtend에서 **파일로 저장**하면 `bongextend-settings-날짜.json`이 생겨요. 안에는 치지직·번역·디시 설정, 항상 번역할 사이트, 탭 순서가 들어가요. 통신사 표처럼 용량이 큰 데이터는 빠져요.

## 단축키
페이지 번역 켜기/끄기 기본 단축키는 `Ctrl+Shift+Y`예요. 번역 탭의 **단축키 설정**에서 원하는 키로 바꿀 수 있어요.

## 개발
`bun install` → `bun run test`(타입 검사 포함) → `bun run build` (결과: `.output/chrome-mv3/`). 자세한 건 `AGENTS.md`, `MERGE_NOTES.md`.
