# BongExtend

치지직, 디시인사이드, 페이지 번역, 다크 모드, 다운로드 관리 기능을 하나로 합친 크롬 확장 프로그램이에요.

## 설치
1. [Releases](https://github.com/Baegovda/BongExtend/releases)에서 `bongextend-버전-chrome.zip`을 받아요 (Source code zip 아님).
2. 압축을 풀어요. 이 폴더가 설치 폴더예요. 지우거나 옮기지 마세요.
3. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 푼 폴더를 골라요. 크롬 109 이상이 필요해요.
4. 예전에 따로 쓰던 치지직·번역·디시 확장은 설정을 옮긴 뒤 지워요 (같이 켜 두면 기능이 두 번 돌아요).

## 팝업
화면 색은 기기의 밝은 화면·어두운 화면을 따라가요. 툴바의 BongExtend 아이콘을 누르면 탭이 가운데에 나와요. 탭을 끌어서 순서를 바꿀 수 있고, 탭에 초점을 둔 뒤 Alt+←/→로도 옮겨요. 로고를 더블클릭하면 처음 순서로 돌아가요. 오른쪽 끝의 마우스 그림은 지금 사이트의 오른쪽 클릭을 되살리고, 오른쪽 아래 톱니는 업데이트·설정이에요. 새 버전이 있으면 톱니에 점이 찍혀요. 확장 프로그램 관리의 왼쪽 탭에서 메일, 환율, 치지직, 번역, 디시, 다크 모드, 다운로더를 열 수 있어요.
- **치지직**: 버퍼링 자동 복구(다음 복구까지 남은 시간을 크게 보여줄 수 있어요), 화질 고정(기본 1080p, 720p·480p·360p도 고를 수 있어요), 선명한 화면, 넓은 화면, 들어가거나 새로고침하면 자동 재생, 영상 위 시청자 수, 채팅 제목 옆 시청자 수, 주간 랭킹 가리기, 후원 랭킹 닉네임 흐리게, 채팅 글씨 크기, 방향키 이동, 팔로잉 목록 새로고침, 관심 스트리머 자동 이동, 광고 가리기(영상은 숨기고 소리는 끄며, 건너뛰기가 켜지면 눌러요), 치트키 안내창 숨기기
- **번역**: 이 페이지만 켜고 끄는 스위치와, 이 사이트를 항상 번역하는 스위치가 따로 있어요. 항상 번역을 켜면 그 사이트 권한을 한 번 물어봐요. Gemini API 키는 **설정 열기**에서 넣어요. 나중에 생기는 글, 페이지 안쪽 칸, 같은 사이트의 창도 번역해요. 마우스를 올리면 나오는 툴팁도 번역해요. 웹페이지와 BongExtend 안의 메일에서 오른쪽 클릭 → **이 페이지 번역하기**로도 시작할 수 있어요. 메일 본문은 발신자의 색과 이미지를 유지하는 밝은 바탕으로 표시해요.
- **디시**: 글 목록 새로고침, 미리보기, 콘텐츠 차단, 메모, 유저 정보, 레이아웃, 글꼴, 이미지 검색, 관리, 글쓰기, 스텔스. 안쪽 탭은 일반, 고급, 차단, 메모, 모듈, 데이터예요. 데이터 탭은 디시 설정만 클라우드에 백업하거나 초기화해요. 차단 목록과 메모 목록은 그 탭에서 따로 복사할 수 있어요.
- **메일**: 여러 Gmail 계정의 읽지 않은 메일을 확인해요. 읽음·보관·삭제는 Gmail에도 반영돼요. **메일 설정**은 BongExtend 창 안에서 열리고 알림·소리·목록 표시·인증번호 자동 복사를 바꿀 수 있어요. 기존 Gmail 로그인 세션을 사용하므로 별도 OAuth 승인이 필요하지 않아요. 로그인 자체는 필요해요. 새 메일 변화는 정상 응답 시 1초 간격으로 확인하며, 네트워크와 계정 상태에 따라 지연될 수 있어요. 오류·로그아웃·서버 제한이 있으면 요청 간격을 늘려요. 인증번호 자동 복사가 성공하면 브라우저 창 중앙에 번호와 복사 완료 문구가 8초간 표시돼요. 30초 간격의 기본 확인도 함께 사용해요.
- **환율**: 원, 달러, 엔, 비트코인처럼 여러 통화를 바꿔 봐요. 금액, 결과, 나라 칸 8개가 팝업 안에 들어가서 더 내리지 않아도 돼요. 나라 색이 옅게 깔리고, 위쪽 환율 탭에는 1달러가 몇 원인지 나와요. 시세는 하루 한 번 갱신되고, 받은 표는 12시간 동안 저장해요.
- **다크 모드**: 모든 사이트 또는 현재 사이트에서 따로 켤 수 있어요. 밝기, 대비, 세피아, 회색조, 배경·글자색과 글꼴을 조절하고 시스템 다크 모드와 사이트 목록을 쓸 수 있어요. 처음 켤 때 필요한 사이트 권한을 물어봐요. 색상 변환은 MIT 라이선스의 Dark Reader 엔진을 사용해요.
- **다운로더**: Chrome 다운로드 목록을 보고 일시 정지·이어받기·취소·다시 받기·열기를 할 수 있어요. 날짜·종류·문자열·정규식으로 거르고, 주소를 여러 개 넣거나 `{1..12}` 범위로 일괄 받을 수 있어요. 현재 페이지에서 보이는 링크·이미지·음성·동영상 주소를 찾아 선택해서 받고, 파일 이름·하위 폴더 규칙과 완료 알림도 설정할 수 있어요. Chrome 제한에 따라 여러 조각 동시 다운로드는 하지 않고, 파일은 기본 다운로드 폴더 아래에 저장해요.

팝업 오른쪽 끝의 **마우스 그림**은 지금 사이트에서 막힌 오른쪽 클릭, 복사, 글자 선택을 되살려요. 켜지면 그림이 밝아지고, 한 번 켜 두면 그 사이트에 다시 들어가도 적용돼요.
- **업데이트·설정**은 오른쪽 아래 톱니예요. 업데이트 확인, 지금 업데이트, 설정 파일로 저장하고 불러오기. 저장 파일에는 Gemini API 키와 항상 번역할 사이트 목록이 들어 있으니 공유하지 마세요.

**모듈 사용** 스위치는 톱니의 설정 안에 모여 있어요. 끄면 그 기능이 꺼져요. 이미 열린 페이지는 새로고침(F5)하면 적용돼요.

**최근 다운로드**는 왼쪽 분류 메뉴와 오른쪽 파일 표로 표시해요. Chrome 기록을 직접 읽고 이름·진행률·크기·속도·남은 시간·주소를 볼 수 있어요. 표는 가로로 스크롤할 수 있고 **크게 보기**를 누르면 넓은 탭에서 열려요. 휴지통은 목록만 정리하고 실제 파일을 삭제하지 않아요.

**다운로더** 탭에서 최근 다운로드, 페이지 파일 찾기, 다운로드 관리자, 다운로드 설정을 앱 안에서 열 수 있어요. 번역 프리즘은 한 번에 최대 16개만 움직이고, 나머지는 원문을 유지한 채 순서를 기다려요. 막대가 지난 글자에 파스텔 잔광이 잠시 남은 뒤 원래 색으로 돌아와요.

## 현재 페이지 영상 받기

**다운로더 → 현재 페이지 영상 받기**를 누르면 현재 보고 있던 페이지의 영상 주소가 채워져요. 직접 영상 주소가 보이지 않으면 페이지 주소를 사용해요. **동영상 받기**에서는 주소를 직접 넣을 수도 있어요. 최대 4K·1440p·1080p·720p 또는 MP3를 선택해 PC에서 내려받아요. 영상과 음성을 합치는 동안에는 창을 닫아도 작업이 이어져요. Chrome을 완전히 종료하면 중단돼요.

처음 한 번 **연결 파일 받기**를 누르고, 같은 화면의 **Windows 보조 프로그램 받기**에서 ZIP을 받아 압축을 풀고 `install.cmd`를 실행해요. Python 3.10 이상이 필요해요. 설치 후 **연결 확인**을 눌러요. 별도 API 키는 필요하지 않아요. 파일은 Windows 다운로드 폴더의 `BongExtend`에 저장해요. 확장 ID가 바뀌면 연결 파일을 다시 받아 설치 프로그램을 실행해 주세요.

다운로더 안의 **동영상 저장 내역**에는 진행률과 최근 30개 저장 기록이 나와요. **경로 복사**를 누르고 파일 탐색기 주소 칸에 붙여 넣으면 저장한 파일에 접근할 수 있어요. 새로 완료된 영상도 다운로더 탭의 뱃지에 합치고, 탭을 열어 확인하면 뱃지를 지워요. **진행 상황 열기**는 이미 열린 영상 받기 탭을 찾아서 보여 줘요.

보조 프로그램은 [yt-dlp](https://github.com/yt-dlp/yt-dlp)와 [FFmpeg](https://github.com/yt-dlp/FFmpeg-Builds)를 공식 배포처에서 내려받고 공개 SHA256으로 확인해요. Node가 없으면 [Deno](https://github.com/denoland/deno)도 설치해요. 지원 사이트·화질은 원본과 도구의 지원 범위에 따라 달라요. DRM 보호 영상과 로그인이 필요한 영상은 지원하지 않아요. 현재 페이지 버튼은 허용된 페이지의 `<video>` 주소를 찾고, `blob:` 주소는 페이지 주소로 처리해요. 임의 사이트의 보호 기능이나 로그인을 우회하지 않아요.

## 업데이트

톱니 안의 **5분마다 자동 업데이트**는 기본으로 켜져 있어요. 새 버전이 감지되면 현재 화면을 유지한 채 백그라운드 탭에서 다운로드·설치하고 확장을 다시 불러와요. 직접 보려면 **업데이트 확인**을 눌러요.

처음 한 번 **자동 업데이트 폴더 지정**에서 크롬에 불러온 BongExtend 폴더(manifest.json이 있는 곳)를 골라요. 저장된 쓰기 권한이 있으면 다음부터 따로 누르지 않아도 설치돼요. 폴더를 옮기거나 Chrome이 권한을 만료시키면 알림에서 다시 지정해 주세요. 중단된 설치도 권한이 있으면 자동으로 이어서 진행해요. 네트워크 오류는 5분 간격으로 한 버전당 최대 3번 자동 시도하고 설정에 결과를 표시해요. 이미 열려 있던 웹페이지는 새로고침(F5)해 주세요.

zip만 받아 직접 덮어쓰려면 **zip 내려받기**를 써요. 그러면 받은 파일을 설치 폴더에 풀어 덮어쓴 뒤, 확장 프로그램 화면에서 새로고침해 주세요.

## 옛 확장에서 설정 옮기기
확장 ID가 새로 바뀌어서 설정이 자동으로 넘어오지 않아요.
- **번역**: 예전 번역 확장이 만든 `bongtrans-settings.json`을 BongExtend 톱니(업데이트·설정) → **파일 불러오기**에 넣어요. Gemini 키도 같이 넘어와요.
- **디시**: 예전 디시 확장 팝업 → 데이터 → **데이터 내보내기**(클립보드에 복사돼요) → BongExtend 톱니(업데이트·설정) → **붙여넣어 불러오기**에 붙여 넣어요.
- **치지직**: 예전 치지직 확장에는 내보내기 버튼이 없어서 치지직 탭에서 다시 설정해 주세요. 관심 스트리머 목록도 그래요.

BongExtend에서 **파일로 저장**하면 `bongextend-settings-날짜.json`이 생겨요. 안에는 치지직·번역·다크 모드·다운로드 관리·디시 설정과 사이트 목록, 탭 순서가 들어가요. 통신사 표처럼 용량이 큰 데이터는 빠져요.

## 단축키
페이지 번역 켜기/끄기 기본 단축키는 `Ctrl+Shift+Y`예요. 번역 탭의 **단축키 설정**에서 원하는 키로 바꿀 수 있어요.

## 개발
`bun install` → `bun run test`(타입 검사 포함) → `bun run build` (결과: `.output/chrome-mv3/`). 인수인계는 `HANDOVER.md`, 꼭 지킬 규칙은 `AGENTS.md`예요.

브라우저 검사는 개인 Chrome 프로필을 사용하지 않고 임시 프로필·로컬 시험 데이터로 실행해요. Windows의 기본 Chrome 경로를 사용하며 다른 위치는 `CHROME_PATH`로 지정해요.

- `bun run test:browser:translation`: 상품 300개 화면에서 번역 효과 수, 긴 멈춤, 스크롤과 글자 재사용을 검사해요.
- `bun run test:browser:modules`: 실제 다운로드·일시 정지·이어받기·다시 받기·목록 제거와 메일 인앱 설정 저장을 검사해요. 이 시험은 임시 확장 복사본에만 선택 권한을 부여해요. `MINIMAL_PERMISSIONS=1`을 지정하면 배포 권한 그대로 검사하고 페이지 파일 찾기는 제외해요.
- `bun run test:browser:chzzk`: Chrome의 실제 암복호화를 거친 광고 결정과 재생 데이터 보존을 검사해요. 생방송 전체 광고 주기를 재현하는 시험은 아니에요.
