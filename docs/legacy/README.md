# 옛 확장 기록

이 폴더의 글은 BongExtend로 합치기 전 기록이에요. 지금 작업 안내가 아니에요.

지금 안내는 저장소 맨 위의 `AGENTS.md`, 그다음 `MERGE_NOTES.md`예요. 저장소는 [Baegovda/BongExtend](https://github.com/Baegovda/BongExtend)예요. `docs/HANDOFF.md`라는 경로는 없어요.

| 파일 | 예전 확장 |
| --- | --- |
| `BongChzzk-CHANGELOG.md` | 치지직 (BongChzzk) |
| `BongTrans-AGENTS.md`, `BongTrans-CHANGELOG.md`, `BongTrans-HISTORY.md` | 번역 (BongTrans) |
| `BongDC-AGENTS.md`, `BongDC-CHANGELOG.md`, `BongDC-HANDOFF.md` | 디시 (BongDC) |

`BongDC-HANDOFF.md`는 예전에 `docs/HANDOFF.md`였던 파일이에요. 아래 글은 당시 내용 그대로 두었어요.
