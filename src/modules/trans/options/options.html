BongExtend 번역

현재 페이지의 보이는 글을 Gemini 또는 DeepL로 번역해요. 키는 이 브라우저에만 저장돼요.

번역 시작 준비

API 키와 언어를 확인하고 저장한 뒤, 번역할 페이지에서 번역을 켜 주세요.

번역 엔진

키는 deepl.com/your-account/keys에서 만들어요. 키가 :fx로 끝나면 무료 요금제로 자동 인식해요. 저장할 때 DeepL 서버 접근을 한 번 허용해 주세요.

무료 키는 Google AI Studio에서 만들어요. 키 페이지: aistudio.google.com/apikey

기본값은 한국어예요. 원문 언어는 문장마다 자동으로 감지해요.

기본 모델이 혼잡(503)하거나 없으면(404) 대체 모델로 넘어가요. 그래도 안 되면 나머지 기본 제공 모델을 한 번 더 시도해요. 키 오류와 할당량 초과는 넘어가지 않아요.

번역 순서와 화면 효과

기본값은 꺼짐이에요. 켜면 화면에 들어온 문장 중 커서에 가까운 것부터 다음 묶음으로 보내요. 이미 보낸 요청은 취소하지 않아요.

기본값은 켜짐이에요. 번역을 기다리는 동안 글자가 천천히 흐려졌다 돌아오고, 번역이 도착하면 잠깐 흐린 글자가 또렷해져요. 배경이나 무지개 줄은 쓰지 않아요. 끄면 바로 바뀌고, 시스템에서 움직임 줄이기를 켜면 움직이지 않는 표시만 보여요.

아낀 문장과 API 호출은 누적이에요. 캐시를 지워도 이 숫자는 남고, 통계 초기화만 0으로 되돌려요. 용량은 번역문과 키의 UTF-8 크기 근사치예요.

기본 보관 기간은 90일이에요. 기간이 지난 항목을 지우고, 용량 한도를 넘으면 마지막 사용이 오래된 항목부터 지워요. 삭제 안 함과 제한 없음을 같이 고르면 자동으로 지우지 않아요.

설정 파일 내보내기·가져오기는 BongExtend 팝업의 업데이트·설정 탭(백업·복원)에서 모든 모듈을 한 번에 해요. 그 파일에는 API 키가 들어 있으니 남에게 보내지 마세요.

업데이트 확인은 BongExtend 팝업의 업데이트·설정 탭에서 해요.

개인정보

번역하는 문장은 사용자의 API 키로 Google Gemini API에 전송돼요. 이 확장 프로그램의 서버는 없어요. 키와 번역 캐시는 이 기기의 chrome.storage.local과 IndexedDB에만 있어요.

무료 등급에서는 입력한 글이 Google 모델 개선에 쓰일 수 있어요. 유료 등급의 데이터 사용 여부는 모델마다 다르니 요금 페이지를 확인해 주세요.
